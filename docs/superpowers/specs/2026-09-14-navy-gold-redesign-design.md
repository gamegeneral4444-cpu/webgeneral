# เปลี่ยนธีมเว็บเป็นกรมท่า–ทอง พร้อมเอฟเฟกต์กระจกเงา

วันที่ 2026-09-14 · แบรนช์ `codex/initial-website`

## เป้าหมาย

เปลี่ยนธีมเว็บไซต์ฝ่ายบริหารงานทั่วไปจากโทน **ส้ม–ทอง–ครีม** ปัจจุบัน เป็นโทน
**กรมท่า–ทอง** ที่ตรงกับตราสัญลักษณ์ GAD ของฝ่าย และเพิ่มเอฟเฟกต์กระจกเงา
(mirror glass) บนพื้นผิวที่รองรับ

ผู้ใช้เลือกไว้แล้วจากหน้าเทียบตัวเลือก: **น.1** (กรมท่าตราจริง) + **ก.2** (กระจกเงามีแสงพาด) + **ล.3** (โลโก้บนแผ่นกระจก)

## สถานะตั้งต้น

- เว็บ production อยู่ที่ https://general-affairs-website.vercel.app/ ต่อ Supabase จริงและมีข้อมูลแล้ว
- ธีมปัจจุบัน `--primary: #b45309` (ส้มอิฐ) · `--gold: #facc15` · `--accent: #fef3c7`
- ส่วนที่เป็นน้ำเงินอยู่แล้ว: ฟุตเตอร์ และ sidebar หลังบ้าน (`--sidebar: #0f172a`)
- ตัวแปรสีถูกรวมศูนย์ไว้ที่ `app/globals.css` เป็นหลัก มีสีฮาร์ดโค้ดหลุดอยู่ **20 จุดใน 13 ไฟล์**

## 2. เอฟเฟกต์กระจกเงา (ก.2)

### สเปก CSS

```css
.glass-mirror {
  background: linear-gradient(125deg,
    rgba(255,255,255,.34) 0%, rgba(255,255,255,.07) 34%,
    rgba(255,255,255,.02) 55%, rgba(255,255,255,.16) 100%);
  backdrop-filter: blur(9px) saturate(150%);
  -webkit-backdrop-filter: blur(9px) saturate(150%);
  border: 1px solid rgba(255,255,255,.30);
  box-shadow: inset 0 1px 0 rgba(255,255,255,.6),
              inset 0 -1px 0 rgba(255,255,255,.12),
              0 14px 34px -18px rgba(0,0,0,.8);
}
/* แถบแสงพาดเฉียง */
.glass-mirror::after {
  content: ""; position: absolute; inset: -60% -20% auto -20%; height: 90%;
  background: linear-gradient(100deg, transparent 38%,
              rgba(255,255,255,.30) 50%, transparent 62%);
  transform: rotate(-14deg); pointer-events: none;
}
```

### ขอบเขตการใช้งาน — สำคัญ

`backdrop-filter` วางบนพื้นสีขาวทึบแล้ว**ไม่เกิดผลใด ๆ** เพราะไม่มีอะไรให้เบลอ
จึงกำหนดชัดว่าใส่ตรงไหนได้บ้าง

**ใส่กระจก (มีพื้นหลังรองรับ)**

| พื้นผิว | ไฟล์ |
|---|---|
| แถบหัวเว็บเมื่อเลื่อนลง (sticky) | `components/public/site-header.tsx` |
| การ์ด/ปุ่มในโซนฮีโร่ | `app/(public)/page.tsx` |
| แถบ CTA ก่อนฟุตเตอร์ | `app/(public)/page.tsx` |
| การ์ดในฟุตเตอร์ | `components/public/site-footer.tsx` |
| กล่องฟอร์มหน้าเข้าสู่ระบบ | `app/login/` |
| sidebar + แถบบนหลังบ้าน | `components/admin/admin-shell.tsx` |
| แผ่นรองโลโก้ (ล.3) | `site-header.tsx`, `admin-shell.tsx` |

**ไม่ใส่กระจก (พื้นขาว ใช้การ์ดขอบทองแทน)**

โซนบริการด่วน · ข่าวประชาสัมพันธ์ · เอกสารดาวน์โหลด · บุคลากร — สี่โซนกลางหน้าแรก
รวมถึงหน้ารายการ/รายละเอียดทั้งหมด และตารางหลังบ้าน

การ์ดบนพื้นขาวใช้: `border` 1px `#E2E6F0` + `border-top` 2px `--gold` + เงาอ่อน

### ทางถอย (fallback)

เบราว์เซอร์ที่ไม่รองรับ `backdrop-filter` ต้องไม่เห็นกล่องโปร่งจนอ่านไม่ออก

```css
@supports not (backdrop-filter: blur(1px)) {
  .glass-mirror { background: rgba(4,18,51,.82); }
}
```

และเคารพ `prefers-reduced-motion` โดยยกเลิก transition ของแถบแสง

## 3. โลโก้ (ล.3)

**ผู้ใช้จะอัปโหลดเอง** ผ่าน `/admin/settings` เพื่อแทนตราศูนย์การศึกษาพิเศษเดิม
เว็บดึงโลโก้จาก `settings.logo_url` ในฐานข้อมูลอยู่แล้ว จึงไม่ต้องแก้ตรรกะส่วนนี้

สิ่งที่ต้องทำในโค้ด:

1. เปลี่ยนกรอบโลโก้บนหัวเว็บจาก **วงกลมพื้นครีมขอบทอง** เป็น **แผ่นกระจกมุมมน**
   (`border-radius: 10px` + `.glass-mirror` อ่อน ๆ) เพื่อไม่ให้ฟันเฟืองรอบตราโดนตัด
2. เตรียมไฟล์ `public/logo.png` (จาก `logo-400.png`) ไว้เป็นค่าตั้งต้นกรณี
   `logo_url` เป็น null — ใช้แทนไอคอน `GraduationCap` ปัจจุบัน มีผลกับ local dev
   และเว็บที่ยังไม่ตั้งค่า ไม่กระทบ CMS
3. เปลี่ยน `app/favicon.ico` และภาพ Open Graph ให้เป็นตรา GAD

ไฟล์ที่เตรียมให้อัป: `logo-400.png` (400×400 โปร่งใส 279 KB)
ไม่ใช้ `logo.png` ต้นฉบับ 2000×2000 เพราะ 1.2 MB ใหญ่เกินสำหรับหัวเว็บ

### ข้อสังเกตที่ต้องตัดสินใจภายหลัง

ชื่อบนตราเขียนว่า **"ฝ่ายบริหารทั่วไป"** แต่ชื่อเว็บและเมนูใช้ **"ฝ่ายบริหารงานทั่วไป"**
(มีคำว่า "งาน") ไม่กระทบงานนี้ แต่ควรเลือกใช้ให้ตรงกันสักทาง

## 5. กล่องว่าง

ข่าวประชาสัมพันธ์และเอกสารดาวน์โหลดยังไม่มีข้อมูล สองโซนนี้กินพื้นที่ราว 25% ของหน้าแรก
ต้องออกแบบให้ดูตั้งใจ ไม่ใช่ดูเหมือนเว็บเสีย: กรอบเส้นประสีกรมท่าจาง ไอคอนหม่น
ข้อความอธิบายสั้น ๆ และ (เมื่อผู้ใช้ล็อกอินเป็นแอดมิน) ปุ่มลัดไปหน้าเพิ่มข้อมูล

## 6. นอกขอบเขต

- ไม่เปลี่ยนโครงหน้า ลำดับเนื้อหา หรือฟอนต์
- ไม่แตะตรรกะฐานข้อมูล สิทธิ์ RLS หรือ Server Actions
- ไม่เปลี่ยนพื้นหลังโซนกลางหน้าเป็นสีเข้มเพื่อให้ใส่กระจกได้ (เป็นงานแยก ถ้าต้องการ)
- ไม่แก้ชื่อ "ฝ่ายบริหารงานทั่วไป" → "ฝ่ายบริหารทั่วไป"

## 7. การตรวจงาน

1. ใส่ค่า Supabase จริงลง `.env.local` เพื่อให้ localhost แสดงข้อมูลเหมือน production
   (ถ้าไม่ใส่ ข่าว/เอกสาร/บุคลากรจะว่าง ตรวจสีได้แต่ตรวจเลย์เอาต์จริงไม่ได้)
2. `npm run build` ต้องผ่าน และ `npm test` ต้องผ่านครบ 30 เทสเหมือนเดิม
3. เทียบภาพหน้าแรก หน้าเข้าสู่ระบบ และแดชบอร์ดหลังบ้าน ทั้งโหมดสว่างและมืด
   ที่ความกว้าง 1440px และ 390px
4. ตรวจว่าไม่มี `amber-` `yellow-` `orange-` หลงเหลือ:
   `grep -rE "(amber|yellow|orange)-[0-9]" app components lib` ต้องได้ผลว่าง
5. ตรวจคอนทราสต์ทุกคู่ในตารางข้อ 1 ด้วยเครื่องมือวัดจริง
